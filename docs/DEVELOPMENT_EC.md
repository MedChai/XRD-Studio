# 蓝电 CEX 与 dQ/dV

从顶栏「打开 CEX」、文件夹、拖放或样品下的 CEX 归档进入蓝电工作区。打开文件后点「dQ/dV」。留空圈号时优先查看充放电均可计算的首圈。手动输入支持单圈、逗号分隔、区间、步长和倒数位置。例为 `1,10,20-60s5,r1`。

- **曲线**支持多文件和多圈。点击曲线点可查对应原始记录和工步。每组最多渲染 24 条曲线，通过上一组和下一组检查其余数据。CSV 包含所选文件、圈号和方向的完整网格。
- **演变**用电压与圈号显示热图。工步彼此独立，缺失圈留空。点热图的有效格子回到该圈曲线。
- **峰分析**用电压窗口内的主峰做逐圈测量。可在曲线上点两条窗口边界。半峰宽和峰高相对窗口两端连线，窗口积分按有效覆盖计算。相对峰位使用同文件同方向、实测电流相近且能唯一定位的基准圈。
- 绝对容量单位为 mAh/V。比容量默认使用 CEX 记录的活性物质质量，也可输入本次分析使用的质量。导出记录质量来源。曲线默认充电为正、放电为负，可切换放电绝对值。

## 数值与追溯

引擎通过已验证的 Windows x64 LANDCex DLL 读取快照，按原生循环和实际恒流工步提取完整记录。恒压容量单列统计，静置和未知工步从微分输入中排除。时间间断、电压跳变及电流阶跃按独立片段处理。原生容量可用时优先采用，缺失或回退时对该段电流按时间积分。重复电压所对应的容量增量保留，电压网格仅覆盖实测区间。可选高斯平滑作用于差分前的累计容量，端点容量保持一致。

默认电压步长 2 mV，默认关闭平滑。平滑宽度以 mV 表示高斯半峰宽。界面显示原始采样间隔和低分辨率提示。峰指标用于同条件比较，跨倍率、温度或截止电压的变化应结合相应测试条件解释。

`cex.dqdv` 按圈分页。结果缓存使用 CEX 的 SHA-256、算法版本、循环号与计算设置，关闭应用后按同一设置可重算。曲线和峰 CSV 记录来源及参数。PNG 配同名溯源文本，SVG 内嵌元数据。

## 接口

| 命令 | 用途 |
| --- | --- |
| `cex.open`、`cex.archive`、`cex.cells` | 打开、归档与列出样品的 CEX |
| `cex.dqdv` | 分批读取所选循环的恒流曲线及诊断 |
| `cex.dqdv_source` | 由原始记录号回查工步及容量–电压点 |
| `cex.dqdv_export_curves`、`cex.dqdv_export` | 流式导出曲线 CSV 与导出峰表 CSV |
| `cex.backup_legacy` | 打包一个样品已有的表格原件、循环统计、旧分析和缓存 |

## 历史数据

样品库通过格式区分 CEX 归档与旧表格记录。旧表格和结果保留在库内，在样品下选择「导出历史表格备份」可以保存 ZIP。ZIP 的 manifest 会标记库内原件缺失的条目。有对应原始 CEX 时，可把 CEX 归档到同一样品并使用当前算法。
