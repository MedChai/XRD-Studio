## 0. 一页摘要

**做什么**：把 LAND 导出的循环数据拖进 XRD Studio，自动算出每圈的 dQ/dV 曲线，追踪各相变峰（H1→H2、H2→H3 等）的位置、面积、宽度随循环的演化，最终把容量衰减**定量拆分**为三种机制，并给出"这颗电池主要死于什么"的结论。

**核心价值**：

1. 现在你看容量保持率曲线，只能知道"衰减了多少"；这个工具告诉你"衰减**为什么**"——极化涨了（界面/动力学问题）还是活性物质没了（颗粒开裂/相变破坏），两者对应完全不同的材料改进方向（包覆/电解液 vs 烧结/掺杂/单晶化）。
2. H2→H3 相变起始电压与峰面积的逐圈追踪，是无钴高镍体系结构健康度最敏感的单项指标，单独成图。
3. 与你已有的 XRD 结构分析（混排度、c/a、峰分裂）放在同一软件里：循环 100 圈后峰面积萎缩 + XRD 显示 (108)/(110) 合并 → 直接在项目内交叉印证表面重构/体相退化。

**诚实声明（方法论边界）**：经典的 Dahn 式 LLI/LAM（锂库存损失/活性物质损失）拆解是**全电池**方法，需要正负极半电池参比曲线。你目前以 Li 半电池为主（锂片是无限锂库），所以本计划采用的是**半电池适用**的三分量拆解（§2.3），并在数据接口上预留全电池扩展（§10）。我不会把全电池的方法硬套到半电池上给你貌似精确、实则无物理意义的数字。

**规模估计**：engine 约 4–5 个工作日，前端约 2–2.5 个工作日，打包文档 0.5 天。每个里程碑独立可验收、可中断。

## 2. 方法论（半电池版衰减归因）

这是整个工具的科学核心，先讲清楚再讲实现。

### 2.1 dQ/dV 的计算

对第 n 圈的恒流充电（或放电）段：

1. **电荷积分**：Q(t) = ∫ I·dt（梯形积分，逐记录点累加）。归一化到活性物质质量得 mAh/g（质量由导入时填写，或直接采用 LAND 导出的比容量列，两者互相校验，偏差 >2% 报 QA 警告）。
2. **电压网格重采样**：把 Q(V) 插值到均匀电压网格（默认 ΔV = 2 mV，可调 1–10 mV）。这一步天然过滤掉静置段和记录间隔不均的影响。
3. **微分**：dQ/dV = ΔQ/ΔV，再经 Savitzky–Golay 平滑（默认 window=11 点、polyorder=3，可调）。
4. **恒压段（CV）单独统计**：CV 段的 dQ/dV 在截止电压处发散，不进曲线；但其容量占比（CV 容量/总充电容量）是阻抗增长的旁证，作为单独指标输出。

### 2.2 相变峰的识别与追踪

无钴高镍层状正极（R-3m）在 2.7–4.3 V 窗口内的特征峰（vs. Li/Li⁺，默认值，可按材料微调）：

| 窗口键 | 过程 | 默认区间 (V) | 物理含义 |
|---|---|---|---|
| `H1H2` | H1→H2 单相/两相转变 | 3.55–3.80 | 主体脱锂 |
| `H2H3` | H2→H3 相变（c 轴塌缩） | 4.10–4.30 | **核心指标**：体积收缩 ~4–5%，颗粒开裂源头 |
| `Ni2` | 高压区镍氧化宽峰 | 4.0 以上重叠 | 兜底窗口，供自定义 |

每个圈每方向在窗口内用 `scipy.signal.find_peaks`（prominence 自适应阈值 = 窗口内 MAD 的倍数）找峰，跨圈用"窗口内最近邻 + 容差"匹配成**峰轨迹（track）**。每条轨迹逐圈记录：

- **峰位 V_p(n)**：充放电两侧峰位差 ΔV_pp = V_p,chg − V_p,dis 为该过程的极化量度；峰位绝对漂移包含极化 + 热力学变化（相变起始电压上移 ≙ 阻抗增长）；
- **峰面积 A(n)**（窗口内 ∫dQ/dV·dV = 该相变贡献的容量）：**准平衡下的活性物质度量**，萎缩 = 参与该相变的物质减少或不可逆化；
- **半高宽 FWHM(n)**：变宽 = 相分布弥散/颗粒间不均匀性增加。

**H2→H3 专项**：起始电压定义为 dQ/dV 首次超过该窗口峰高 10% 的最低电压，逐圈追踪。它是无钴高镍最常用的健康度单指标，直接对应 c 轴塌缩行为。

### 2.3 衰减三分量归因（半电池适用）

对第 n 圈，同倍率下：**总衰减 ΔQ(n) = Q(1) − Q(n)**，拆为三个分量（求和=总量，按构造闭合）：

**① 极化型损失（Polarization）**——"材料还在，但电压够不着了"
- **首选方法 A（有低倍率回访圈时，最准）**：若循环制度中定期插入 C/10 或更低的回访圈（工具自动识别：电流 ≤ 主倍率 1/5 的圈），则 极化损失(n) = Q(n, 主倍率) − Q(n, 低倍率插值)；活性物质损失 = Q(1, 低倍率) − Q(n, 低倍率)。
- **退化方法 B（无回访圈，近似）**：用峰位位移估算：ΔQ_pol ≈ ΔV_pp(n) 增量 × 窗口内平均 |dQ/dV|。结果标注"低置信度"，并在报告里建议补测制度（每 50 圈插一个 C/10 圈，成本几乎为零，归因质量提升一个档次）。

**② 活性物质型损失（LAM，Material）**——"参与反应的物质没了"
- 各相变峰面积萎缩率 A_k(n)/A_k(1)，按首圈各过程容量占比加权：ΔQ_LAM = Σ_k w_k·(1 − A_k(n)/A_k(1))·Q_k(1)。
- **判别规则**（写进自动结论文本）：
  - 所有峰**等比例**萎缩 → 真活性物质损失（失联/开裂/惰性化）；
  - **只有高端峰（H2→H3）萎缩**且放电末端容量同步损失 → 更可能是窗口截断型（见③），提示先别下"材料死了"的结论。

**③ 窗口截断型损失（Window-cutoff）**——"容量被极化推到了窗口外"
- 高压侧极化增大 → 充电在 4.3 V 截止时实际脱锂量减少。由高端峰的位移 × 该区 dQ/dV 斜率估算。

**输出形态**：
- 归因堆叠面积图（x=圈数，y=各分量损失，总和=总衰减曲线）；
- 分量表（CSV 可导出）；
- 库仑效率 CE(n)、累积不可逆容量 ∑(1−CE)·Q_c 作为**副反应强度指标**单列（在半电池中它不直接等于容量损失，但与极化增长强相关，放图上对照看）；
- 自动结论文本，规则示例：
  > "200 圈衰减 12.4%：极化型 58%（H2→H3 充放峰位差从 21 mV 增至 87 mV，且低倍率回访圈容量仅降 4%）——建议优先排查界面/电解液方向；活性物质型 34%（各峰等比例萎缩）伴随 XRD (108)/(110) 分裂度下降——存在颗粒开裂与表面重构的联合证据。"

### 2.4 与 XRD 结构分析的联动

同一项目（样品）下，电化学 cell 与 XRD 数据集挂接，趋势页（`trend` 已有）扩展数据源：混排度、c/a、峰分裂度 vs 圈数与峰面积、H2→H3 起始电压放同一张对比图。这是"结构-电化学交叉印证"的落点，也是这个工具区别于通用电池软件的地方。

## 3. LAND 数据解析（M0 的核心，也是最大风险点）

### 3.1 支持的格式

| 格式 | 读取方式 | 说明 |
|---|---|---|
| `.xlsx` | `openpyxl`（新增依赖） | 新版蓝电客户端导出，多工作表 |
| `.xls` | `xlrd`（新增依赖） | 老版导出的二进制格式 |
| `.csv` / `.txt` | 标准库 `csv` | **编码自动探测（GBK/GB18030/UTF-8 BOM）**——蓝电中文导出默认 GBK，这是最容易翻车的地方 |

**不引入 pandas**：现有 engine 依赖只有 numpy + scipy，解析用 openpyxl/xlrd 的行接口 + numpy 足够，保持安装包体积和 PyInstaller 打包的可控性。

### 3.2 列映射策略

蓝电不同型号/软件版本的表头名称不一致（"状态"、"工步"、"循环次数"、"电压(V)"、"电流(mA)"、"比容量(mAh/g)"、"记录时间"…）。策略分三层：

1. **自动识别**：内置同义词表 + 模糊匹配（电压/电流/时间/状态/循环/容量六类必需列），命中即用；
2. **解析预览**：导入向导先 dry-run，把识别结果（每类列映射到哪一列、分出多少圈、首末圈参数）展示给用户确认，映射错了可以在 UI 里手动指定；
3. **记忆**：确认过的映射规则存为项目的列映射预设（沿用现有 `presets` 机制），同源文件下次全自动。

### 3.3 分圈与工步切分

- 优先用导出文件自带的循环序号/工步列；
- 缺失时从"状态"序列重构（充电→[恒压]→静置→放电→静置 = 一圈）；
- 每圈记录：方向、恒流/恒压/静置分段、平均电流（换算 C 倍率，需要导入时填额定容量或由首圈估计）、充放容量、CE、电压窗口实际值。

### 3.4 数据 QA（导入即出，拒绝垃圾进垃圾出）

- 时间戳单调性（跳跃/回退 → 标记可疑段）；
- 积分容量 vs LAND 容量列偏差 >2% → 警告（电流符号约定问题或记录抽稀）；
- 记录间隔中位数 > 30 s → 警告"dQ/dV 分辨率不足，建议蓝电软件里调密记录间隔"；
- 静置段数据落点异常、容量为 0 的空圈、首圈活化异常 → 圈级标记，分析时可过滤。

## 附录 B：LAND 导出列勾选清单（已确认，2026-10-06）

用户的蓝电软件导出对话框分「记录表」「循环表」两组，以下为确认的最小勾选集（M0 列映射同义词表以此为准）：

### 记录表（必须 6 + 建议 2）

- **必须**：测试时间、电压、电流、循环序号、工步序号、工步状态
- **建议**：容量（积分校验）、工步主参数（工步设定电流 → C 倍率与 C/10 回访圈识别）
- **可选**：温箱温度
- **不勾**：记录序号、步骤时间、SOC|DOD、能量、比能量、功率、dQ/dV、dV/dQ（蓝电自算，平滑不受控，引擎统一自算）、系统时间、全部辅助通道、充电/放电容量与能量（逐条累计值，自积分）

### 循环表（一行一圈，文件小，多拿）

- **必须**：循环序号、充电容量、放电容量、效率
- **建议**：充电比容量、放电比容量、放电中压、充电中压、恒流充入容量、恒流充入容量比、充电 DCIR、放电 DCIR、容量保持率、放电终压、充电时间、放电时间
- **不勾**：各类能量项、能量效率、电容、rd/rd2、全部放电平台容量

### 解析利好

导出原生含 循环序号/工步序号/工步状态，§3.3 的"从状态序列重构分圈"兜底路径退为保险；工步主参数使 C/10 回访圈自动识别（§2.3 方法 A）可直接落地。导出侧注意：记录间隔选最密一档（文件大小靠砍列不砍行）。
